\section{Overview of the Proposed Framework}
\label{sec:method_overview}

To address the limitations of standard LayoutLMv3 on document key information extraction, we propose a structure-aware architecture that enhances the backbone at multiple stages. The framework introduces four practical components:
\begin{enumerate}
    \item \textbf{Hierarchical Position Encoding (HPE):} Replaces flat 2D coordinate embeddings with a hierarchical representation that explicitly groups tokens into reading lines, columns, and logical blocks before self-attention.
    \item \textbf{Segment Context Module (SCM):} Pools token representations into text-line vectors, models interactions across lines using a lightweight Transformer encoder, and injects segment context back into tokens with a ReZero gating mechanism and segment-start embeddings.
    \item \textbf{Intra-Line Boundary Loss ($\mathcal{L}_{\text{bound}}$):} Supervise adjacent token pairs on the same line using an auxiliary binary classifier, penalizing incorrect entity transitions and reducing span fragmentation.
    \item \textbf{Cross-Modal Contrastive Loss ($\mathcal{L}_{\text{cont}}$):} Aligns contextualized text tokens with their corresponding visual image patches, encouraging the model to retain strong visual-textual consistency during fine-tuning.
\end{enumerate}

Figure~\ref{fig:proposed_architecture} illustrates the overall pipeline of our proposed architecture. Unlike earlier exploration that experimented with gated late-fusion between token and segment streams, our final model directly classifies the segment-enriched token representations, keeping the classification head simple and computationally lightweight.

\section{Hierarchical Position Encoding}
\label{sec:method_hpe}

In baseline LayoutLMv3, each normalized coordinate $(x_0, y_0, x_1, y_1, w, h)$ of token $i$ is looked up independently in an embedding table. While this preserves coordinate values, it does not explicitly tell the model which words lie on the same line or which text blocks belong together.

To provide clear structural cues, our Hierarchical Position Encoding (HPE) organizes bounding boxes into three hierarchical levels using geometric heuristics during preprocessing:

\begin{enumerate}
    \item \textbf{Line Grouping ($id_l$):} Two horizontally adjacent word boxes are assigned to the same reading line if their vertical overlap exceeds $50\%$ of the height of the shorter box:
    \begin{equation}
        \frac{\min(y_1^{(i)}, y_1^{(j)}) - \max(y_0^{(i)}, y_0^{(j)})}{\min(h_i, h_j)} \ge 0.5.
    \end{equation}
    Words within the same line are sorted from left to right.

    \item \textbf{Column Detection ($id_c$):} Within a line, if the horizontal gap between two consecutive words exceeds $12\%$ of the total page width, the line is divided into separate column slots. This separation helps the model handle multi-column forms and invoice headers.

    \item \textbf{Block Grouping ($id_b$):} Consecutive reading lines are grouped into a common block if the vertical gap between them is less than $1.8$ times the median line height of the document page. This step groups sentences into coherent paragraphs or key-value fields.
\end{enumerate}

After determining the indices $(id_l, id_c, id_b)$ for token $i$, we map each index to a 128-dimensional embedding vector using lookup tables $\mathbf{E}_{\text{line}}$, $\mathbf{E}_{\text{col}}$, and $\mathbf{E}_{\text{block}}$. We concatenate these three vectors into a $384$-dimensional descriptor and project it to match the backbone hidden size $d$ using a linear matrix $\mathbf{W}_{\text{hier}} \in \mathbb{R}^{384 \times d}$:
\begin{equation}
    \mathbf{e}_{\text{hier}}(i) = \mathbf{W}_{\text{hier}} \left[ \mathbf{E}_{\text{line}}(id_l) \;\|\; \mathbf{E}_{\text{col}}(id_c) \;\|\; \mathbf{E}_{\text{block}}(id_b) \right].
    \label{eq:hpe_embedding}
\end{equation}

Finally, $\mathbf{e}_{\text{hier}}(i)$ is scaled by a weighting factor $\beta$ and added to the standard token input embeddings:
\begin{equation}
    \mathbf{e}_i^{\text{total}} = \mathbf{e}_i^{\text{text}} + \beta \cdot \mathbf{e}_{\text{hier}}(i).
\end{equation}
In our experiments, we set $\beta = 1.0$, which provides balanced spatial guidance without dominating the pretrained text features.

\section{Segment Context Module}
\label{sec:method_scm}

While the LayoutLMv3 backbone contextualizes tokens using self-attention, classifying tokens independently can still lead to inconsistent labels within a multi-word field. The Segment Context Module (SCM) addresses this by allowing text segments to exchange information before final token classification.

Let $\mathbf{H} = (\mathbf{h}_1, \dots, \mathbf{h}_L) \in \mathbb{R}^{L \times d}$ denote the token hidden states produced by the LayoutLMv3 encoder. Based on the OCR text line segmentation, each token $i$ is associated with a line segment index $s_i \in \{0, 1, \dots, S-1\}$. The module operates in three steps:

\subsection{Step 1: Segment Aggregation via Mean Pooling}
For each segment $k \in \{0, \dots, S-1\}$, let $\mathcal{S}_k = \{i \mid s_i = k\}$ be the set of tokens belonging to segment $k$. We compute a compact segment representation $\mathbf{s}_k$ by averaging the hidden states of its constituent tokens:
\begin{equation}
    \mathbf{s}_k = \frac{1}{|\mathcal{S}_k|} \sum_{i \in \mathcal{S}_k} \mathbf{h}_i.
    \label{eq:segment_mean_pool}
\end{equation}
This operation compresses the sequence of $L$ tokens into $S$ segment representations, where $S \ll L$.

\subsection{Step 2: Inter-Segment Contextualization}
The pooled segment vectors $(\mathbf{s}_0, \dots, \mathbf{s}_{S-1})$ are ordered according to their reading sequence on the page. We add a learnable segment-position embedding $\mathbf{E}_{\text{seg}}(k)$ to each vector and process the sequence with a lightweight 1-layer Transformer encoder:
\begin{equation}
    \mathbf{c}_k = \text{TransformerEncoder}\big(\mathbf{s}_k + \mathbf{E}_{\text{seg}}(k)\big).
\end{equation}
This allows each segment (such as an answer field) to directly attend to neighboring segments (such as its corresponding question label).

To ensure that the newly initialized Transformer encoder does not disrupt the pretrained representations during early training steps, we apply a ReZero residual connection \cite{bachlechner2021rezero}. A learnable scalar parameter $g$, initialized to $0.0$, controls the contribution of the contextualized segment state:
\begin{equation}
    \mathbf{s}'_k = \mathbf{s}_k + g \cdot (\mathbf{c}_k - \mathbf{s}_k).
    \label{eq:rezero_segment}
\end{equation}

\subsection{Step 3: Segment Broadcast and Onset Embedding}
We broadcast the refined segment representation $\mathbf{s}'_{s_i}$ back to each constituent token $i$. To help the classifier distinguish the first token of an entity (\texttt{B-} tag) from continuation tokens (\texttt{I-} tag), we detect segment transitions using a binary indicator:
\begin{equation}
    f_i = \mathds{1}[i = 1 \;\vee\; s_i \neq s_{i-1}].
\end{equation}
This indicator looks up a learnable onset embedding $\mathbf{e}_{\text{first}}(f_i) \in \mathbb{R}^d$. The final contextualized token representation is computed as:
\begin{equation}
    \mathbf{h}_i^{\text{final}} = \mathbf{h}_i + \mathbf{s}'_{s_i} + \mathbf{e}_{\text{first}}(f_i).
    \label{eq:final_token_repr}
\end{equation}

\section{Classification and Intra-Line Boundary Loss}
\label{sec:method_boundary_loss}

The final token states $\mathbf{h}_i^{\text{final}}$ are fed directly into a linear classifier with dropout to compute token logits $\mathbf{z}_i = \mathbf{W}_{\text{cls}} \mathbf{h}_i^{\text{final}} + \mathbf{b}_{\text{cls}} \in \mathbb{R}^{|\mathcal{Y}|}$. The primary sequence labeling objective is the standard Cross-Entropy loss over valid non-padding tokens:
\begin{equation}
    \mathcal{L}_{\text{CE}} = -\frac{1}{|\mathcal{V}_{\text{valid}}|} \sum_{i \in \mathcal{V}_{\text{valid}}} \log \frac{\exp(z_{i, y_i})}{\sum_{c=1}^{|\mathcal{Y}|} \exp(z_{i, c})}.
    \label{eq:ce_loss}
\end{equation}

In addition to token cross-entropy, we introduce an auxiliary Intra-Line Boundary Loss ($\mathcal{L}_{\text{bound}}$) to help the model identify where entities start and end on the same line. For each adjacent token pair $(i, i+1)$ that shares the same reading line ($s_i = s_{i+1}$), we concatenate their representations and pass them through a two-layer MLP boundary classifier:
\begin{equation}
    p_{i, i+1}^{\text{bound}} = \sigma\Big(\mathbf{W}_2 \, \text{ReLU}\big(\mathbf{W}_1 [\mathbf{h}_i^{\text{final}} \;\|\; \mathbf{h}_{i+1}^{\text{final}}] + \mathbf{b}_1\big) + b_2\Big).
\end{equation}

We assign a ground-truth binary label $t_{i, i+1}^{\text{bound}}$ based on whether tokens $i$ and $i+1$ belong to the same entity:
\begin{equation}
    t_{i, i+1}^{\text{bound}} = 
    \begin{cases}
        0, & \text{if tokens } i \text{ and } i+1 \text{ share the same entity}, \\
        1, & \text{if token } i+1 \text{ transitions to another entity or background}.
    \end{cases}
\end{equation}
The boundary loss is computed using binary cross-entropy over all valid intra-line pairs:
\begin{equation}
    \mathcal{L}_{\text{bound}} = -\frac{1}{|\mathcal{P}_{\text{intra}}|} \sum_{(i, i+1) \in \mathcal{P}_{\text{intra}}} \Big[ t_{i, i+1}^{\text{bound}} \log p_{i, i+1}^{\text{bound}} + (1 - t_{i, i+1}^{\text{bound}}) \log (1 - p_{i, i+1}^{\text{bound}}) \Big].
    \label{eq:bce_boundary_loss}
\end{equation}
This loss penalizes the model when it fails to detect entity transitions within the same horizontal line.

\section{Cross-Modal Contrastive Loss}
\label{sec:method_contrastive_loss}

Document images provide important visual indicators, such as background color, font weight, and dividing lines, that complement text. However, during downstream fine-tuning, standard classification heads only propagate gradients back through the text representations, which can cause the visual patch features to drift \cite{wang2023aetnet}.

To maintain strong alignment between modalities, we implement a cross-modal Contrastive Loss ($\mathcal{L}_{\text{cont}}$). Let $\mathbf{v}_p \in \mathbb{R}^d$ denote the visual patch representations produced by the image branch, and let $\mathbf{h}_i^{\text{final}}$ denote the contextualized text token representations. For each token $i$, we identify the visual patch $p(i)$ whose spatial coordinates cover the center of the token's bounding box $\mathbf{b}_i$.

We project both representations into a normalized 128-dimensional shared space using linear projections $\mathbf{g}_{\text{text}}$ and $\mathbf{g}_{\text{img}}$:
\begin{equation}
    \mathbf{z}_i^{\text{text}} = \frac{\mathbf{g}_{\text{text}}(\mathbf{h}_i^{\text{final}})}{\|\mathbf{g}_{\text{text}}(\mathbf{h}_i^{\text{final}})\|_2}, \quad
    \mathbf{z}_p^{\text{img}} = \frac{\mathbf{g}_{\text{img}}(\mathbf{v}_p)}{\|\mathbf{g}_{\text{img}}(\mathbf{v}_p)\|_2}.
\end{equation}

For a batch of matched pairs $(i, p(i))$, the contrastive loss pulls matching text-patch pairs together while pushing non-matching patches apart using an InfoNCE formulation with temperature parameter $\tau = 0.07$:
\begin{equation}
    \mathcal{L}_{\text{cont}} = -\frac{1}{N_{\text{text}}} \sum_{i=1}^{N_{\text{text}}} \log \frac{\exp\big((\mathbf{z}_i^{\text{text}})^\top \mathbf{z}_{p(i)}^{\text{img}} \,/\, \tau\big)}{\sum_{p'} \exp\big((\mathbf{z}_i^{\text{text}})^\top \mathbf{z}_{p'}^{\text{img}} \,/\, \tau\big)}.
    \label{eq:contrastive_loss}
\end{equation}

This objective encourages the model to ground text tokens in their local visual appearance, improving recognition accuracy on degraded or low-contrast document scans.

\section{Joint Training and Optimization}
\label{sec:joint_objective}

The full model is trained end-to-end by minimizing the combined loss function:
\begin{equation}
    \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \lambda_{\text{bound}} \mathcal{L}_{\text{bound}} + \lambda_{\text{cont}} \mathcal{L}_{\text{cont}},
    \label{eq:total_loss}
\end{equation}
where $\lambda_{\text{bound}}$ and $\lambda_{\text{cont}}$ are hyperparameters that balance the auxiliary objectives. In our primary experiments, we set $\lambda_{\text{bound}} = 0.2$ and $\lambda_{\text{cont}} = 0.1$. Importantly, both the boundary classifier and contrastive projections are used only during training. At inference time, token predictions are produced directly from $\mathbf{z}_i$ via $\text{argmax}$, introducing zero additional inference latency.

Algorithm~\ref{alg:forward_training} summarizes the complete forward pass and training procedure.

\begin{algorithm}[htbp]
\SetAlgoLined
\DontPrintSemicolon
\KwIn{Batch of tokenized documents $\mathcal{B} = \{(\mathbf{w}, \mathbf{b}, \mathbf{s}, \mathbf{I}, \mathbf{y})\}$; weights $\lambda_{\text{bound}} = 0.2, \lambda_{\text{cont}} = 0.1$.}
\KwOut{Token predictions $\hat{\mathbf{Y}}$ and joint loss $\mathcal{L}_{\text{total}}$.}

\BlankLine
\textbf{1. Hierarchical Layout Encoding}\;
Compute line $id_l$, column $id_c$, and block $id_b$ indices for all tokens\;
Lookup embeddings and project: $\mathbf{e}_{\text{hier}} \leftarrow \mathbf{W}_{\text{hier}} [\mathbf{E}_{\text{line}} \| \mathbf{E}_{\text{col}} \| \mathbf{E}_{\text{block}}]$\;
Construct text input: $\mathbf{e}_i^{\text{total}} \leftarrow \mathbf{e}_i^{\text{text}} + \beta \mathbf{e}_{\text{hier}}(i)$\;

\BlankLine
\textbf{2. Multimodal Transformer Encoding}\;
Extract image patches $\mathbf{E}^{\text{image}}$ from image $\mathbf{I}$\;
Pass concatenated sequence $[\mathbf{E}^{\text{total}} \| \mathbf{E}^{\text{image}}]$ through LayoutLMv3 backbone\;
Extract token hidden states $\mathbf{H} = (\mathbf{h}_1, \dots, \mathbf{h}_L)$ and patch states $\mathbf{V}$\;

\BlankLine
\textbf{3. Segment Context Modeling}\;
Mean-pool tokens into segment vectors: $\mathbf{s}_k \leftarrow \frac{1}{|\mathcal{S}_k|} \sum_{i \in \mathcal{S}_k} \mathbf{h}_i$\;
Refine segment representations with ReZero gate: $\mathbf{s}'_k \leftarrow \mathbf{s}_k + g(\mathbf{c}_k - \mathbf{s}_k)$\;
Broadcast back to tokens with onset embedding: $\mathbf{h}_i^{\text{final}} \leftarrow \mathbf{h}_i + \mathbf{s}'_{s_i} + \mathbf{e}_{\text{first}}(f_i)$\;

\BlankLine
\textbf{4. Predictions and Multi-Task Loss Computation}\;
Compute classification logits: $\mathbf{Z} \leftarrow \mathbf{W}_{\text{cls}} \mathbf{h}_i^{\text{final}} + \mathbf{b}_{\text{cls}}$\;
Calculate Cross-Entropy loss $\mathcal{L}_{\text{CE}}$ using Equation~\ref{eq:ce_loss}\;
Compute Boundary Loss $\mathcal{L}_{\text{bound}}$ over intra-line token pairs using Equation~\ref{eq:bce_boundary_loss}\;
Compute Contrastive Loss $\mathcal{L}_{\text{cont}}$ between text tokens and visual patches using Equation~\ref{eq:contrastive_loss}\;
\Return{$\hat{\mathbf{Y}} = \text{argmax}(\mathbf{Z})$ and $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \lambda_{\text{bound}} \mathcal{L}_{\text{bound}} + \lambda_{\text{cont}} \mathcal{L}_{\text{cont}}$}\;
\caption{Forward pass and joint training of the proposed architecture}
\label{alg:forward_training}
\end{algorithm}
