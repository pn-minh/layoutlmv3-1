\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

Automating structured data extraction from scanned administrative forms, tax declarations, commercial invoices, and retail receipts is a critical requirement across modern enterprise workflows in finance, healthcare, logistics, and public administration. Unlike plain-text natural language corpora, Visually Rich Documents (VRDs) convey semantics jointly through lexical content, two-dimensional geometric layout, and visual typography. A numeric string on a receipt derives its meaning—whether unit price, tax amount, or grand total—from its tabular row alignment, column header, and font prominence.

While multimodal Vision-Language Transformers such as LayoutLMv3 unify subword tokens, 2D bounding coordinates, and linear image patch projections within a single backbone, adapting the baseline model directly to downstream Key Information Extraction (KIE) exposes four recurring structural limitations:
\begin{enumerate}
    \item \textbf{Cross-column coordinate ambiguity:} Embedding $(x_0, y_0, x_1, y_1)$ as flat coordinates provides no explicit inductive bias for reading lines, multi-column boundaries, or paragraph blocks.
    \item \textbf{Intra-segment label jitter and key-value disconnection:} Classifying each BPE subword token in isolation frequently yields conflicting entity tags inside a single multi-token phrase and fails to propagate semantic labels from form keys to standalone values.
    \item \textbf{Intra-line boundary bleeding:} When a field prompt and its filled value appear consecutively on the same horizontal line (e.g., \texttt{TO: George Baroody}), standard token cross-entropy frequently merges both spans into a single entity.
    \item \textbf{Cross-modal representation drift under visual clutter:} Fine-tuning solely with token classification loss allows visual patch representations to drift or attract spurious attention from scanning borders, hole punches, and background watermarks.
\end{enumerate}

To address these challenges, I design and evaluate a structure-aware LayoutLMv3 architecture comprising Hierarchical Position Encoding (HPE), a ReZero-gated Segment Context Module (SCM) with segment-onset embeddings, an Intra-Line Boundary Loss, and a calibrated Cross-Modal Contrastive Loss with detached visual patch anchors. Both auxiliary losses regularize representation learning exclusively during training and are discarded at test time, preserving the exact inference latency and memory footprint of the backbone classifier.

This thesis is organized into five chapters:
\begin{itemize}
    \item \textbf{Chapter 1 (Introduction):} Formulates the VRD Key Information Extraction problem, explicitly specifies the model's multimodal inputs and structured entity outputs, outlines real-world industrial applications, and summarizes my core contributions.
    \item \textbf{Chapter 2 (Background and Related Work):} Reviews multimodal document representation, 2D spatial-aware attention, the LayoutLM architecture family, and recent structural and contrastive tuning methods.
    \item \textbf{Chapter 3 (Proposed Methodology):} Presents the mathematical formulation and architectural design of HPE, SCM, Intra-Line Boundary Loss, and calibrated Cross-Modal Contrastive Loss.
    \item \textbf{Chapter 4 (Experiments and Results):} Details my experimental setup on an NVIDIA A100 GPU, benchmark statistics on FUNSD and CORD, contrastive calibration findings, multi-seed evaluation results, leave-one-out ablation studies, and boundary error analysis.
    \item \textbf{Chapter 5 (Conclusion):} Summarizes the main findings of my research, analyzes current architectural limitations, and outlines concrete directions for future work.
\end{itemize}
