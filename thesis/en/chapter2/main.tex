\section{Multimodal Document Representation}
\label{sec:foundational_knowledge}

\subsection{OCR Serialization and Subword Alignment in VRDs}
\label{subsec:vrd_ocr}

Unlike plain text, Visually Rich Documents (VRDs) require joint modeling of lexical tokens, 2D spatial geometry, and visual rendering \cite{cui2021documentai}. Standard pipelines first apply Optical Character Recognition (OCR) to detect word-level bounding boxes $\tilde{\mathbf{b}}_i$ and transcribe character strings, which are subsequently normalized to the integer coordinate domain $[0, 1000]^4$ (Equation~\ref{eq:doc_representation}) to ensure scale invariance across heterogeneous scan resolutions.

When Byte-Pair Encoding (BPE) \cite{sennrich2016neural,liu2019roberta} splits a single OCR word into $m > 1$ subword tokens $(w_{i,1}, \dots, w_{i,m})$, all constituent subwords inherit the parent word's normalized bounding box $\mathbf{b}_i$ and OCR line segment index $s_i$. Under standard IOB2 sequence labeling \cite{ramshaw1995text}, cross-entropy supervision and \texttt{seqeval} entity decoding are restricted strictly to the initial subword $w_{i,1}$, while continuation subwords $(w_{i,2}, \dots, w_{i,m})$ are masked with label index $-100$ so that subword fertility does not skew gradient magnitudes or boundary evaluation.

\subsection{2D Spatial-Aware Multimodal Attention}
\label{subsec:transformer_attention}

To fuse textual and visual streams within a single Transformer \cite{vaswani2017attention}, modern document backbones concatenate $L$ text token embeddings with $M+1$ visual patch embeddings into a unified sequence $\mathbf{H} \in \mathbb{R}^{(L+M+1) \times d}$. Because standard 1D sinusoidal or learned position embeddings capture only serialized reading order, LayoutLMv2 \cite{xu2021layoutlmv2} and LayoutLMv3 \cite{huang2022layoutlmv3} inject explicit 2D spatial biases into the pre-softmax attention logits of each head $h$:
\begin{equation}
    \mathbf{A}_h = \text{softmax}\!\left( \frac{\mathbf{Q}_h \mathbf{K}_h^\top}{\sqrt{d_k}} + \mathbf{B}^{\text{1D}}_{\text{rel}} + \mathbf{B}^{\text{2D-}x}_{\text{rel}} + \mathbf{B}^{\text{2D-}y}_{\text{rel}} \right),
    \label{eq:spatial_attention}
\end{equation}
where $\mathbf{B}^{\text{1D}}_{\text{rel}}(i,j)$ encodes relative 1D sequence distance $|i - j|$, while $\mathbf{B}^{\text{2D-}x}_{\text{rel}}(i,j)$ and $\mathbf{B}^{\text{2D-}y}_{\text{rel}}(i,j)$ are learnable bucketed biases indexed by the horizontal and vertical coordinate offsets $(x_0^{(i)} - x_0^{(j)})$ and $(y_0^{(i)} - y_0^{(j)})$. While these pairwise biases capture continuous coordinate deltas, they remain agnostic to discrete structural boundaries—such as whether two horizontally separated tokens belong to the same reading line or to adjacent columns in a multi-column form.

\section{The LayoutLM Architecture Family}
\label{sec:layoutlm_evolution}

\subsection{Evolution from LayoutLM to LayoutLMv2}
\label{subsec:layoutlm_v1_v2}

LayoutLM \cite{xu2020layoutlm} extended BERT \cite{devlin2019bert} by summing 2D coordinate embeddings $(x_0, y_0, x_1, y_1)$ with subword embeddings during Masked Visual-Language Modeling on IIT-CDIP scans, relying on an external Faster R-CNN detector only during downstream fine-tuning. LayoutLMv2 \cite{xu2021layoutlmv2} integrated a ResNeXt-FPN convolutional visual backbone directly into pre-training alongside spatial-aware self-attention (Equation~\ref{eq:spatial_attention}) and cross-modal Text-Image Alignment objectives. However, the convolutional feature extractor introduced substantial parameter overhead and region-alignment bottlenecks.

\subsection{LayoutLMv3 Backbone}
\label{subsec:layoutlmv3_backbone}

LayoutLMv3 \cite{huang2022layoutlmv3} eliminates heavy CNN backbones by adopting Vision Transformer (ViT) linear patch projections \cite{dosovitskiy2020image}, as illustrated in Figure~\ref{fig:layoutlmv3_arch}.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.86\textwidth]{chapter2/architecture.png}
    \caption{Architecture of the LayoutLMv3 backbone, unifying segment-shared 2D text embeddings and linear image patch projections under joint MLM, MIM, and WPA pre-training \cite{huang2022layoutlmv3}.}
    \label{fig:layoutlmv3_arch}
\end{figure}

Its input representation comprises two streams:
\begin{enumerate}
    \item \textbf{Text Embedding Stream:} Each BPE subword $w_i$ combines its token embedding, 1D position embedding, token-type embedding, and 6-tuple 2D box embedding $(x_0, y_0, x_1, y_1, w, h)$:
    \begin{equation}
        \mathbf{e}_i^{\text{text}} = \text{LN}\!\left( \mathbf{e}^{\text{word}}(w_i) + \mathbf{e}^{\text{pos1D}}(i) + \mathbf{e}^{\text{type}}(0) + \mathbf{e}^{\text{pos2D}}(\mathbf{b}_i) \right).
        \label{eq:layoutlmv3_text_emb}
    \end{equation}
    Instead of noisy word-level boxes, LayoutLMv3 assigns identical segment-level bounding coordinates to all words within the same OCR text line.
    \item \textbf{Visual Patch Stream:} The $224 \times 224$ page image $\mathbf{I}$ is split into $M = 196$ patches of $16 \times 16$ pixels, linearly projected to $\mathbb{R}^d$, summed with learnable 1D visual position embeddings, and prepended with $[\texttt{CLS}_{\text{vis}}]$.
\end{enumerate}
Pre-trained on 11 million IIT-CDIP pages using Masked Language Modeling (MLM), Masked Image Modeling (MIM, reconstructing discrete dVAE visual tokens), and Word-Patch Alignment (WPA), LayoutLMv3 provides a strong foundation for document understanding.

\section{Related Work in Structural and Cross-Modal Document KIE}
\label{sec:related_work_kie}

\subsection{Topological Layout and Segment Modeling}

Recent studies demonstrate that flat 2D coordinate embeddings are insufficient for complex multi-column and tabular layouts. StructuralLM \cite{li2021structurallm} grouped words into shared 2D cell embeddings to capture form regions, while BROS \cite{hong2022bros} encoded relative spatial offsets between bounding box vertices to improve reading-order robustness. Graph-based architectures such as FormNet \cite{lee2022formnet} and GraphLayoutLM \cite{li2023graphlayoutlm} constructed explicit layout graphs over neighboring text segments to mitigate serialization distortion, and ROAP \cite{xie2026roap} injected reading-order-aware relative position biases derived from an Adaptive-XY-Gap tree.

Unlike approaches that require custom graph attention kernels or full re-pretraining on millions of pages, my Hierarchical Position Encoding (HPE) and Segment Context Module (SCM) inject multi-scale layout topology (line, column, block) and inter-segment reading context directly into an off-the-shelf LayoutLMv3 checkpoint via ReZero residual gating \cite{bachlechner2021rezero}.

\subsection{Cross-Modal Alignment and Boundary Supervision}

During downstream KIE fine-tuning, optimizing token cross-entropy alone leaves the visual patch stream without direct supervision, allowing cross-modal alignment to degrade \cite{wang2023aetnet}. AETNet \cite{wang2023aetnet} addressed this by introducing patch-token contrastive objectives during fine-tuning, while DocExtractNet \cite{yan2025docextractnet} combined cross-modal feature enhancement with side-tuning to handle noisy scans. However, my empirical analysis reveals that applying symmetric InfoNCE directly to post-segment token representations creates gradient interference with token boundary classification on smaller backbones. I resolve this limitation by decoupling pre-SCM contrastive alignment with stop-gradient visual anchors from post-SCM classification and pairing it with explicit Intra-Line Boundary supervision.
