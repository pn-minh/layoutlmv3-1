\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
Key Information Extraction (KIE) from Visually Rich Documents (VRDs)—such as administrative forms, commercial invoices, and retail receipts—plays a foundational role in modern Document Artificial Intelligence (Document AI) and Robotic Process Automation (RPA). Multimodal pre-trained Transformers, most notably LayoutLMv3, have achieved remarkable progress by jointly modeling text, two-dimensional (2D) layout coordinates, and visual patch representations through unified masked pre-training. However, standard token-level sequence-labeling architectures built on LayoutLMv3 exhibit three fundamental structural and contextual limitations: (1) heavy reliance on flat, absolute 2D bounding box coordinates forces global self-attention to implicitly infer macroscopic document structures such as horizontal text lines, localized blocks, and vertical columns; (2) independent per-token classification lacks explicit reading-order context propagation across neighboring segments, resulting in severe BIO label drift within long multi-token entities; and (3) the absence of explicit pairwise boundary supervision between adjacent tokens causes entity fragmentation or erroneous merging across intra-line entity transitions.

To overcome these challenges simultaneously without requiring costly additional pre-training, this thesis investigates and proposes an enhanced architectural framework built upon LayoutLMv3 (implemented in \texttt{LayoutLMv3For}\allowbreak\texttt{SegmentTokenClassification}) that integrates three synergistic components: (1) \textbf{Hierarchical Position Encoding (HPE)}, which clusters token bounding boxes via spatial heuristics into line, block, and damped column indices to inject explicit macroscopic layout priors into input embeddings; (2) a \textbf{Token-Segment / Segment Context Module (SCM)}, which mean-pools intra-segment token states, propagates reading-order context across segments via a lightweight ReZero-gated Transformer encoder, and broadcasts enriched representations back to tokens alongside a learnable \texttt{is\_first\_}\allowbreak\texttt{token\_embedding} to preserve BIO prefix transitions; and (3) an \textbf{Intra-Line Entity Boundary Loss}, which trains a pairwise binary MLP classifier over pre-pooled adjacent token states supervised by contiguous entity identifiers (\texttt{entity\_ids}). Rigorous 3-seed evaluation ($\{42, 123, 1993\}$) on an NVIDIA A100-SXM4-80GB GPU across the FUNSD and CORD benchmarks demonstrates that our proposed framework improves entity-level F1 on FUNSD from $89.92 \pm 0.85\%$ to $91.58 \pm 0.16\%$ ($+1.66\%$ F1 gain while reducing cross-seed standard deviation by over $5.3\times$) at the \texttt{base} scale, while maintaining high accuracy and stability on the CORD receipt benchmark.

\textbf{\textit{Keywords:}} Key Information Extraction (KIE), Visually Rich Documents (VRDs), LayoutLMv3, Hierarchical Position Encoding (HPE), Segment Context Module (Token-Segment / SCM), Intra-Line Boundary Loss, BIO Sequence Labeling.
