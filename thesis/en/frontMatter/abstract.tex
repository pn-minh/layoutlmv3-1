\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Key Information Extraction (KIE) from visually rich documents, such as scanned forms and receipts, is an essential task in automated document processing. Modern multimodal Transformers like LayoutLMv3 combine text, 2D coordinates, and visual patch representations to parse these documents effectively. However, when adapting LayoutLMv3 to entity labeling tasks, several practical issues remain. Because the baseline treats 2D bounding boxes as flat coordinates, it cannot explicitly represent document structures such as reading lines, columns, or logical blocks. In addition, when tokens inside a multi-word entity are classified independently, the model frequently produces inconsistent label sequences. Adjacent fields on the same line, such as a question label next to its answer, also tend to merge into a single entity.

To address these limitations, this thesis proposes a structure-aware architecture based on LayoutLMv3. We introduce three main components: Hierarchical Position Encoding (HPE), a Segment Context Module (SCM), and an Intra-Line Boundary Loss, along with a cross-modal Contrastive Loss. HPE clusters token bounding boxes into lines, columns, and blocks to provide explicit structural position signals. SCM pools token representations within each line segment, applies a lightweight Transformer encoder with a ReZero gate to exchange context across segments, and adds a segment-start embedding to maintain proper entity boundaries. The boundary loss supervises adjacent token pairs on the same line to reduce label fragmentation, while the contrastive loss aligns visual patches with text tokens.

We evaluate the proposed model on two benchmark datasets, FUNSD and CORD, using three random seeds (42, 123, and 1993) on an NVIDIA A100 GPU. On the FUNSD dataset, our base model achieves an entity-level F1 score of 91.58\%, improving over the 89.92\% baseline while reducing standard deviation across runs from 0.85\% down to 0.16\%. On CORD, the model maintains high accuracy and improves precision on fine-grained receipt fields.
